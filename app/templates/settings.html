سرور Ollama را چطور آماده کنم که از بیرون وصل شود؟
  1. Ollama به‌طور پیش‌فرض فقط به خود همان سرور جواب می‌دهد. روی سرور Ollama بزن: sudo systemctl edit ollama
  2. این دو خط را اضافه و ذخیره کن: [Service] و Environment="OLLAMA_HOST=0.0.0.0:11434"
  3. sudo systemctl restart ollama
  4. Ollama رمز ندارد؛ پورت را فقط برای آی‌پی سرور این داشبورد باز کن: sudo ufw allow from IP-این-سرور to any port 11434
  5. مدل را اگر نداری دانلود کن: ollama pull qwen2.5:14b — لیست مدل‌ها: ollama list
