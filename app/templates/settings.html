هوش مصنوعی

مدلی که مقاله‌ها و پست‌ها را می‌نویسد. سرور هوش مصنوعی خودت را این‌جا وصل کن، ذخیره کن و بعد «تست اتصال» را بزن.

سرور Ollama را چطور آماده کنم که از بیرون وصل شود؟
  1. Ollama به‌طور پیش‌فرض فقط به خود همان سرور جواب می‌دهد. روی سرور Ollama بزن: sudo systemctl edit ollama
  2. این دو خط را اضافه کن و ذخیره کن: [Service] و Environment="OLLAMA_HOST=0.0.0.0:11434"
  3. sudo systemctl restart ollama
  4. Ollama رمز ندارد؛ پورت را فقط برای آی‌پی سرور این داشبورد باز کن: sudo ufw allow from IP-این-سرور to any port 11434
  5. مدل را اگر نداری دانلود کن، مثلاً: ollama pull qwen2.5:14b — لیست مدل‌ها: ollama list

UTM: utm_source = پلتفرم، utm_medium = social / article، utm_campaign = اسم کمپین، utm_content = کد همان پست. با این کار گوگل آنالیتیکس هر کمپین را جدا گزارش می‌کند. لینک کوتاه ({{ settings.public_url or 'آدرس عمومی داشبورد' }}/r/...) هر کلیک را در «گزارش‌ها» می‌شمارد و بازدیدکننده را به سایت می‌فرستد؛ فقط برای پست‌ها، نه مقاله‌ها، تا ارزش سئوی بک‌لینک حفظ شود. اگر می‌خواهی در پست‌ها خودِ آدرس سایت دیده شود، این تیک را بردار؛ آن‌وقت کلیک‌ها با UTM در گوگل آنالیتیکسِ سایت شمرده می‌شوند. {% if not settings.public_url %}برای لینک کوتاه «آدرس عمومی این داشبورد» را بالا پر کن.{% endif %}
لازم نیست برای هیچ لینکی کاری بکنی: هر لینک در هر پلتفرم خودکار برچسب و کد جدا می‌گیرد و جدا شمرده می‌شود. گوگل آنالیتیکس هم برای هر سایت جداست؛ Measurement ID و Property ID هر سایت را در صفحه‌ی سایت‌ها ← ویرایش همان سایت وارد کن. این‌جا فقط یک بار سرویس‌اکانت گوگل را بگذار تا هدف در آنالیتیکس همه‌ی سایت‌ها خودکار ساخته شود و گزارششان بیاید.
سرویس‌اکانت را چطور بسازم؟ (یک بار، ۵ دقیقه)
  1. console.cloud.google.com ← یک پروژه ← APIs & Services ← Library ← «Google Analytics Admin API» و «Google Analytics Data API» را Enable کن.
  2. IAM & Admin ← Service Accounts ← Create service account ← اسم ← Done. روی آن بزن ← Keys ← Add key ← JSON ← فایل دانلود می‌شود.
  3. کل محتوای فایل JSON را در کادر بالا بگذار و ذخیره کن.
  4. در گوگل آنالیتیکسِ هر سایت: Admin ← Property access management ← + ← ایمیل سرویس‌اکانت (client_email داخل فایل) با نقش Editor. همان یک ایمیل برای همه‌ی سایت‌ها کافی است.
  5. در صفحه‌ی ویرایش هر سایت Property ID آن را بنویس و ذخیره کن؛ هدف (Key event) nexa_click خودکار در آنالیتیکس همان سایت ساخته می‌شود.
